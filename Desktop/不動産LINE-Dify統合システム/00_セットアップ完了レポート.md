## 🔧 システムコンポーネント

### 1. Google Drive監視システム (`google_drive/`)

**機能:**
- 10分間隔でGoogle Driveを自動監視
- 新規ファイル・更新ファイルを検出
- Difyナレッジベースへ自動アップロード

**ファイル:**
- `drive_watcher.py` - メインスクリプト（352行）
- `requirements.txt` - 依存パッケージ
- `drive-watcher.service` - systemdサービス設定

**対応形式:**
- PDF、Excel（.xlsx）、CSV、テキストファイル

---

### 2. Dify設定 (`dify_config/`)

**ワークフロー:**
- 3つのナレッジベースを並列検索
- 検索結果の統合・重複排除・ソート
- Claude Sonnet 4による結果整形

**パイプライン（3つ）:**
1. **SUUMO物件パイプライン** - PDF解析、テキスト抽出、ベクトル化
2. **自社管理物件パイプライン** - Excel/CSV解析、構造化データ処理
3. **元付け業者資料パイプライン** - PDF解析、メタデータ抽出

---

### 3. LINE Bot (`line_bot/`)

**機能:**
- Webhook受信（`/callback`エンドポイント）
- 画像受信・保存
- 会話フロー管理（名前・電話番号収集）
- Slack/メール通知

**会話フロー:**
```
1. お客様が物件画像を送信
   ↓
2. ボット「お名前を教えてください」
   ↓
3. お客様が名前入力
   ↓
4. ボット「電話番号を教えてください」
   ↓
5. お客様が電話番号入力
   ↓
6. ボット「詳しい資料をお送りしますか？」
   ↓
7. お客様「はい」
   ↓
8. Slack通知 → スタッフ対応
```

**リッチメニュー:**
- 物件検索（Dify起動）
- 営業時間確認
- 内見予約
- 電話する

## 🚀 次のステップ

### 1. Google Cloud Platform設定

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. 新しいプロジェクト作成
3. Google Drive API有効化
4. サービスアカウント作成
5. 認証情報JSON作成・ダウンロード

### 2. Google Driveフォルダ作成

1. 以下の3つのフォルダを作成:
   - SUUMO物件
   - 自社管理物件
   - 元付け業者資料

2. サービスアカウントに「編集者」権限を付与

3. 各フォルダのIDをコピー（URLの最後の部分）

4. デモデータをアップロード:
   - `demo_data/suumo/*.txt` → SUUMO物件フォルダ
   - `demo_data/jissha/*.csv` → 自社管理物件フォルダ
   - `demo_data/mototsuke/*.txt` → 元付け業者資料フォルダ

### 3. Hostinger VPS設定

1. VPSに接続:
   ```bash
   ssh root@your-vps-ip
   ```

2. プロジェクトファイルを転送:
   ```bash
   scp -r 不動産LINE-Dify統合システム root@your-vps-ip:/tmp/
   ```

3. セットアップスクリプト実行:
   ```bash
   cd /tmp/不動産LINE-Dify統合システム/deployment
   chmod +x setup.sh
   sudo bash setup.sh
   ```

4. 環境変数設定:
   ```bash
   cd /opt/real_estate_line_dify
   cp deployment/.env.template .env
   nano .env
   ```

### 4. Dify設定

1. [Dify](https://dify.ai/) にログイン

2. 3つのナレッジベースを作成:
   - SUUMO物件
   - 自社管理物件
   - 元付け業者資料

3. ワークフローを作成（`dify_config/workflow.yml` を参考）

4. APIキーを作成

### 5. LINE Developers設定

1. [LINE Developers Console](https://developers.line.biz/console/) にログイン

2. Messaging APIチャネル作成

3. Webhook URL設定:
   - `http://your-vps-ip:3001/callback`

4. チャネルシークレット・アクセストークンを取得

5. リッチメニュー設定（オプション）

### 6. サービス起動

```bash
sudo systemctl start drive-watcher
sudo systemctl start line-bot
sudo systemctl enable drive-watcher
sudo systemctl enable line-bot
```

### 7. 動作確認

1. Google Driveにテストファイルアップロード
2. 10分待機
3. Difyで検索確認
4. LINEボットに「こんにちは」と送信
5. 物件画像送信テスト

## 🔐 セキュリティ対策

### 推奨設定

1. **SSL/TLS証明書（Let's Encrypt）**
   ```bash
   sudo certbot --nginx -d your-domain.com
   ```

2. **ファイアウォール強化**
   ```bash
   sudo ufw deny 3001/tcp  # 直接アクセスを拒否
   # Nginxリバースプロキシ経由のみ許可
   ```

3. **.envファイル保護**
   ```bash
   chmod 600 .env
   chown www-data:www-data .env
   ```
